# context-alert

התראה בתוך Claude Code, ברגע שהשיחה נהיית יקרה.

[English](README.md)

## הבעיה

העלות של שיחה ב-Claude Code היא הגודל שלה והזמן שהיא חיה, לא גודל המשימה.

- כל צעד קורא מחדש את כל השיחה. תיקון קטן בשיחה של 400K טוקנים עולה פי כמה מאותו תיקון בשיחה חדשה.
- למטמון של השיחה יש תוקף. חוזרים לשיחה גדולה אחרי הפסקה, וכל השיחה נכתבת מחדש במחיר מלא.
- אף אחד לא מודיע כשזה קורה. מגלים בחשבון, או כשהמכסה השבועית נגמרת באמצע השבוע.

מדדנו שבוע עבודה אחד שלנו: 39 מתוך 49 שיחות עברו 200K טוקנים, ו-13 עברו 500K. השיחות הרגילות עלו פי 9 מכל האוטומציות המתוזמנות שלנו יחד.

## מה זה עושה

הכלי קורא את הגודל האמיתי של השיחה, וברגע הנכון גורם ל-Claude לעצור ולשאול אתכם:

1. **שיחה חדשה עם סיכום (מומלץ).** Claude כותב סיכום מלא, והעבודה ממשיכה בשיחה חדשה.
2. **לסכם כאן.** אתם מריצים `/compact`.
3. **להמשיך כרגיל.** הרמה הזו לא תשאל שוב.

ההתראה קופצת:

- כשהשיחה עוברת 100K, 200K ו-400K טוקנים, פעם אחת לכל רמה;
- כשחוזרים אחרי שעה או יותר לשיחה של 100K טוקנים ומעלה.

אחרי `/compact` או `/clear` הרמות נדרכות מחדש. בכל שגיאה הכלי יוצא בשקט, כך שהוא לא יכול לחסום עבודה. הוא לא שולח שום דבר לשום מקום: קובץ פייתון אחד שקורא קובץ מקומי.

## התקנה

צריך Claude Code ו-Python 3.8 ומעלה. עובד בטרמינל, באפליקציית הדסקטופ ובשיחות ענן. לא עובד בצ'אט של claude.ai, כי אין בו hooks.

### כפלאגין (מומלץ)

בתוך Claude Code:

```
/plugin marketplace add niroavra/claude-context-alert
/plugin install context-alert@nirox
```

### ידנית

1. מעתיקים את `scripts/context-alert.py` אל `~/.claude/hooks/context-alert.py`.
2. ממזגים את `settings-snippet.json` לתוך `~/.claude/settings.json` (לכל הפרויקטים) או לתוך `.claude/settings.json` של פרויקט אחד.

לשיחות ענן משתמשים בדרך של הפרויקט: שומרים את הסקריפט בריפו, למשל ב-`.claude/hooks/context-alert.py`, ומפנים אליו את שתי הפקודות ב-`.claude/settings.json` דרך `"$CLAUDE_PROJECT_DIR/.claude/hooks/context-alert.py"`.

## הגדרות

הכל רשות, כמשתני סביבה (אפשר בבלוק `env` של `settings.json`).

| משתנה | ברירת מחדל | משמעות |
|---|---|---|
| `CONTEXT_ALERT_LEVELS` | `100000,200000,400000` | רמות הטוקנים שמקפיצות התראה |
| `CONTEXT_ALERT_COLD_MIN` | `60` | כמה דקות הפסקה נחשבות חזרה קרה |
| `CONTEXT_ALERT_COLD_TOKENS` | `100000` | השיחה הקטנה ביותר שמצדיקה התראת חזרה |
| `CONTEXT_ALERT_LANG` | `en` | שפת שורת ההודעה: `en` או `he` |

השאלה עצמה נשאלת בשפה שבה אתם כותבים.

איזה רמות מתאימות לכם: במודל עם חלון של 200K יקפצו רק רמת 100K והחזרה הקרה, כי Claude Code מסכם את השיחה לפני 200K. בחלון של 1M כל השלוש רלוונטיות. אם העצירה ב-100K מוקדמת מדי, קבעו `CONTEXT_ALERT_LEVELS=200000,400000`.

## בונוס: תקרה לשיחה

בחלון של 1M, Claude Code מסכם את השיחה לבד רק כשהחלון כמעט מלא. משתנה סביבה אחד מוריד את התקרה:

```
CLAUDE_CODE_AUTO_COMPACT_WINDOW=400000
```

בשיחות ענן מגדירים אותו בהגדרות הסביבה (אי אפשר להגדיר אותו מתוך שיחה). בטרמינל, בבלוק `env` של `~/.claude/settings.json`. אצלנו הוא פועל בסביבות הענן: השיחות שם מסתכמות בערך ב-350K.

## הסרה

פלאגין: `/plugin uninstall context-alert@nirox`. ידנית: מוחקים את שתי שורות ה-hook מ-`settings.json` ואת הסקריפט. תיקיית המצב: `~/.claude/context-alert`.
